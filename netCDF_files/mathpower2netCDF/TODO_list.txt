Bus Data Format
        1   bus number (positive integer)									-> NodeName
        2   bus type														-> not usefull, except reference node ?
                PQ bus          = 1
                PV bus          = 2
                reference bus   = 3
                isolated bus    = 4
        3   Pd, real power demand (MW)										-> ActivePowerDemand
        4   Qd, reactive power demand (MVAr)								-> not yet in NetworkBlock
        5   Gs, shunt conductance (MW demanded at V = 1.0 p.u.)				-> not yet in NetworkBlock
        6   Bs, shunt susceptance (MVAr injected at V = 1.0 p.u.)			-> Susceptance
        7   area number, (positive integer)									-> Usefull ?
        8   Vm, voltage magnitude (p.u.)									-> not yet in NetworkBlock
        9   Va, voltage angle (degrees)										-> not yet in NetworkBlock
   (-)     (bus name)
        10  baseKV, base voltage (kV)									
        11  zone, loss zone (positive integer)								-> Usefull ?
    (+) 12  maxVm, maximum voltage magnitude (p.u.)							-> not yet in NetworkBlock
    (+) 13  minVm, minimum voltage magnitude (p.u.)							-> not yet in NetworkBlock

    Generator Data Format
        1   bus number															-> GeneratorNode
    (-)     (machine identifier, 0-9, A-Z)										-> InitialPower (in ThermalUnitBlock)
        2   Pg, real power output (MW)											-> to add in ThermalUnitBlock
        3   Qg, reactive power output (MVAr)									-> to add in ThermalUnitBlock
        4   Qmax, maximum reactive power output (MVAr)							-> to add in ThermalUnitBlock
        5   Qmin, minimum reactive power output (MVAr)
        6   Vg, voltage magnitude setpoint (p.u.)								-> to add in ThermalUnitBlock
    (-)     (remote controlled bus index)
        7   mBase, total MVA base of this machine, defaults to baseMVA
    (-)     (machine impedance, p.u. on mBase)
    (-)     (step up transformer impedance, p.u. on mBase)
    (-)     (step up transformer off nominal turns ratio)
        8   status,  >  0 - machine in service									-> preprocess: delete in the converter if out of service ?
                     <= 0 - machine out of service
    (-)     (% of total VAr's to come from this gen in order to hold V at
                remote bus controlled by several generators)
        9   Pmax, maximum real power output (MW)								-> MaxPower (in ThermalUnitBlock)
        10  Pmin, minimum real power output (MW)								-> MinPower (in ThermalUnitBlock)
    (2) 11  Pc1, lower real power output of PQ capability curve (MW)			-> Usefull ?
    (2) 12  Pc2, upper real power output of PQ capability curve (MW)			-> Usefull ?
    (2) 13  Qc1min, minimum reactive power output at Pc1 (MVAr)				-> Usefull ?
    (2) 14  Qc1max, maximum reactive power output at Pc1 (MVAr)				-> Usefull ?
    (2) 15  Qc2min, minimum reactive power output at Pc2 (MVAr)				-> Usefull ?
    (2) 16  Qc2max, maximum reactive power output at Pc2 (MVAr)				-> Usefull ?
    (2) 17  ramp rate for load following/AGC (MW/min)							-> Usefull ?
    (2) 18  ramp rate for 10 minute reserves (MW)								-> Usefull ?
    (2) 19  ramp rate for 30 minute reserves (MW)								-> Usefull ?
    (2) 20  ramp rate for reactive power (2 sec timescale) (MVAr/min)			-> Usefull ?
    (2) 21  APF, area participation factor

    Branch Data Format
        1   f, from bus number													-> StartLine
        2   t, to bus number													-> EndLine
    (-)     (circuit identifier)
        3   r, resistance (p.u.)												-> not yet in NetworkBlock
        4   x, reactance (p.u.)													-> not yet in NetworkBlock
        5   b, total line charging susceptance (p.u.)							-> not yet in NetworkBlock
        6   rateA, MVA rating A (long term rating), set to 0 for unlimited		-> Usefull ?
        7   rateB, MVA rating B (short term rating), set to 0 for unlimited		-> Usefull ?
        8   rateC, MVA rating C (emergency rating), set to 0 for unlimited		-> Usefull ?
        9   ratio, transformer off nominal turns ratio ( = 0 for lines )		-> Usefull ?
            (taps at 'from' bus, impedance at 'to' bus,
             i.e. if r = x = b = 0, then ratio = Vf / Vt)
        10  angle, transformer phase shift angle (degrees), positive => delay	-> not yet in NetworkBlock
    (-)     (Gf, shunt conductance at from bus p.u.)							-> Will be necessary for AC
    (-)     (Bf, shunt susceptance at from bus p.u.)							-> Will be necessary for AC
    (-)     (Gt, shunt conductance at to bus p.u.)								-> Will be necessary for AC
    (-)     (Bt, shunt susceptance at to bus p.u.)								-> Will be necessary for AC
        11  initial branch status, 1 - in service, 0 - out of service			-> preprocess: delete in the converter if out of service ?
    (2) 12  minimum angle difference, angle(Vf) - angle(Vt) (degrees)
    (2) 13  maximum angle difference, angle(Vf) - angle(Vt) (degrees)			-> not yet in NetworkBlock
            (The voltage angle difference is taken to be unbounded below
             if ANGMIN < -360 and unbounded above if ANGMAX > 360.
             If both parameters are zero, it is unconstrained.)

             																	-> data missing in matpower instance: MinPowerFlow and MaxPowerFlow

  (+) Generator Cost Data Format
        NOTE: If gen has ng rows, then the first ng rows of gencost contain
        the cost for active power produced by the corresponding generators.
        If gencost has 2*ng rows then rows ng+1 to 2*ng contain the reactive
        power costs in the same format.
        1   model, 1 - piecewise linear, 2 - polynomial
        2   startup, startup cost in US dollars
        3   shutdown, shutdown cost in US dollars
        4   N, number of cost coefficients to follow for polynomial             -> in ThermalUnitBlock:
            cost function, or number of data points for piecewise linear            * CostModel (to add)
        5 and following, parameters defining total cost function f(p),              * StartUp (already in)
            units of f and p are $/hr and MW (or MVAr), respectively.               * Shutdown (to add)
            (MODEL = 1) : p0, f0, p1, f1, ..., pn, fn                               * PowerCostCoeffs[NumberCostCoeffs] (to add)
                where p0 < p1 < ... < pn and the cost f(p) is defined by            * Reactive part to add
                the coordinates (p0,f0), (p1,f1), ..., (pn,fn) of the
                end/break-points of the piecewise linear cost function
            (MODEL = 2) : cn, ..., c1, c0
                n+1 coefficients of an n-th order polynomial cost function,
                starting with highest order, where cost is
                f(p) = cn*p^n + ... + c1*p + c0
